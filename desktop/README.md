# GetMuvi para Windows

Versão desktop do GetMuvi com a mesma proposta da versão Android.

## Recursos

- análise de link antes do download;
- vídeo + áudio, somente vídeo e somente áudio;
- qualidades exibidas conforme disponibilidade;
- MP3, M4A, Opus, original e WebM quando disponível;
- playlists;
- pasta padrão `Downloads/GetMuvi` ou pasta personalizada;
- barra de progresso;
- cancelamento;
- botão **Abrir pasta** após o download;
- FFmpeg embarcado no executável.

## Distribuição

O workflow `Build GetMuvi Windows` gera dois arquivos:

- `GetMuvi.exe`: versão portátil;
- `GetMuvi-Setup-0.1.0.exe`: instalador para Windows.

> A assinatura de código do Windows não é incluída nesta versão de teste. Para remover avisos do Microsoft Defender SmartScreen de forma legítima é necessário um certificado de assinatura de código válido.
